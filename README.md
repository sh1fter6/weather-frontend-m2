# ChileClima - Módulo 6

Aplicación del clima construida como Single Page Application (SPA) para el Módulo 6 del portafolio.
Desarrollada con **Vue 3**, **Vite** y **Vue Router**.

## Características
- Consumo de la API real de Open-Meteo.
- Buscador reactivo de ciudades usando `v-model`.
- Sistema de enrutamiento con vista principal y vista de detalle (pronóstico de 7 días).
- Diseño moderno con Glassmorphism usando CSS nativo, sin frameworks de estilos externos.
- Sistema de Fallback en caso de que la API agote el límite de peticiones.

## Instalación y Ejecución Local
1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Iniciar servidor de desarrollo:
   ```bash
   npm run dev
   ```
